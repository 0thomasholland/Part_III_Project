\subsection{Mathematical Framework}

For most readers, the mathematical framing given below should be sufficient to understand the remainder of the paper, however for full details for the mathematical framework surrounding the underlying python packages can be found see apendix E of Heathcotte and Al-Attar blah TKTK, which lay outside the scope of this report. Other useful texts for a wider background are included in the Mathematical Bibliography (ref TKTK).

% Paragraph: Introduce the function space setting. Explain that fields are  represented as elements of a Sobolev space over the sphere, and why this is appropriate (smoothness, well-defined inner product). Introduce notation.

To represent continuous fields over the sphere (taken to be a unit sphere, $\mathbb{S}^2$, scaled to the dimensions of the Earth) in a mathematically rigorous way, we work within a Sobolev space (\autoref{eq:sobolev}), where the index $s$ controls the smoothness of admissible fields. In practice this means that realisations of the fields are guaranteed to be spatially smooth, which is physically appropriate given the length scales and physical problem involved. For a full explanation see section 2.3.2 of \textcite{heathcoteScaleableBayesianFramework2026}.




\begin{equation}\label{eq:sobolev}
    h \in H^s(\mathbb{S}^2)
\end{equation}

This framework accommodates both deterministic fields, which enter as fixed elements of $H^s(\mathcal{S}^2)$, and Gaussian random fields, which are represented as probability measures over the same space, allowing uncertainty to be propagated consistently through the forward model and for Linear Operators to be functions on both types.

% Paragraph: Introduce linear operators mapping between fields, and their adjoints. This is the machinery used throughout the forward model.

Linear operators map between fields, with their TKTK 



\begin{align}
    A: X &\rightarrow Y \\
    A^*: Y &\rightarrow X
\end{align}

Such that:

\begin{align}
	\braket{Ax,y}_Y = \braket{x, A^*y}_X
\end{align}

% Paragraph: Introduce Gaussian measures over these spaces. A Gaussian field is characterised by a mean and covariance operator. Connect to the structure -- covariance operators are self-adjoint by definition.

The Gaussian fields over spaces are defined by their mean value and covariance, which in the context of this framework are a vector and linear operator matrix respectively. 

\begin{equation}
    \mu = \mathcal{N}(\mathbf{m}, \mathcal{C}), \quad \mathcal{C} = \mathcal{C}^*
\end{equation}

Linear operators can act on these Gaussians such:

\begin{align}
	A&: X \rightarrow Y\\
	\mu_X &= \mathcal{N}(\mathbf{m}, \mathcal{C}) \in X \\
	A \mu &= \mathcal{N}(A\mathbf{m}, A\mathcal{C}A^*) \in Y
\end{align}

Fields can either be rotationally invariant, such that REF is satsified, or spatially variant, such that there is 

\begin{equation}
	f(\mathbf{x'}) = f(\mathbf{Rx}) = f(\mathbf{x})
\end{equation}


\subsection{Modelling Ice and Firn Thickness Change}
% -------------------------------------------------------------------------

% Paragraph: Motivate the need for a spatial prior on ice thickness change.
% Different physical processes dominate in different regions -- dynamic ice
% loss at margins vs firn compaction in the interior. A spatially uniform
% prior cannot capture this.




% Paragraph: Introduce the base Gaussian measure using the heat kernel on
% the sphere. Explain that this gives a rotationally invariant, spatially
% smooth prior, with the length scale controlling spatial correlation.

\begin{equation}
    \mathcal{C}_0 = \mathcal{K}_t, \quad t \sim \ell^2
\end{equation}

% Paragraph: Introduce the generalised Richards curve as the activator
% function. Define it explicitly. Explain the parameters and what they 
% control physically. Note that parameters are set heuristically to reflect
% known glaciological structure, and could in future be constrained empirically.

\begin{equation}
    \alpha(h) = a + \frac{k - a}{\left(1 + e^{b(x - m)}\right)^{1/\nu}}
\end{equation}

% where x is the standardised thickness (x in [0,1]), a is lower asymptote,
% k upper asymptote, b steepness, m threshold, nu asymmetry parameter

% Paragraph: Explain that the activator modulates the covariance of the 
% ice thickness field via pointwise spatial multiplication. Thick ice 
% suppresses ice melt variance; thin marginal ice enhances it. Write out
% the modified covariance structure.

\begin{equation}
    \mathcal{C}_{\text{ice}} = W \mathcal{C}_0 W^*, \quad W = \text{diag}(\alpha(h))
\end{equation}

% Paragraph: Introduce the complementary firn field. Firn weights are 
% 1 - alpha(h), masked to the ice extent. Ice and firn are therefore
% complementary by construction -- regions of low ice melt probability
% have high firn probability.

\begin{equation}
    \mathcal{C}_{\text{firn}} = \tilde{W} \mathcal{C}_0 \tilde{W}^*, 
    \quad \tilde{W} = \text{diag}(1 - \alpha(h))
\end{equation}

% Paragraph: Explain the GMSL variance rescaling. The prior amplitude is 
% set by requiring the implied global mean sea level change to have a 
% prescribed standard deviation sigma_gmsl. This is a physically meaningful
% way to set the prior scale rather than an arbitrary choice.

\begin{equation}
    \sigma_{\text{gmsl}} = \text{std}(G \circ \mu), 
    \quad \mathcal{C} \rightarrow \left(\frac{\sigma_{\text{target}}}{\sigma_{\text{gmsl}}}\right)^2 \mathcal{C}
\end{equation}


\subsection{Relating Ice Thickness Change to Mass Change}

% Paragraph: Explain that thickness change is converted to surface load via
% density scaling. Ice and firn use different densities, which enters as a
% scalar factor on the thickness-to-load operator.

\begin{equation}
    L = \rho_{\text{ice}} \, A_{\text{load}} \, h_{\text{ice}}, \quad
    L = \rho_{\text{firn}} \, A_{\text{load}} \, h_{\text{firn}}
\end{equation}
