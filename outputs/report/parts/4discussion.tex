\subsection{Error of using SSHC as a proxy for SLC in GMSL estimation}

The key result from the per-source error characterisation is that the proxy error differs in both sign and magnitude across ice sources: Greenland melt leads to a systematic underestimation of GMSL, while West and East Antarctic sources produce a smaller bias of opposite sign. This source dependence means that the SSHC proxy error cannot be corrected by a single scalar factor; the correction would itself depend on the unknown spatial distribution of ice loss. This matches the findings of \textcite{lickleyBiasEstimatesGlobal2018, al-attarReciprocitySensitivityKernels2023}.

At the global scale the resulting error is modest, on the order of 1-10\% depending on expected value and uncertainty; however, regional averages exhibit substantially larger and spatially variable biases, since SSHC and SLC differ by the solid-earth deformation and geoid perturbation terms, which are spatially heterogeneous functions of the ice load distribution. This motivates a more principled inference framework in which the full fingerprint physics is incorporated into the estimation procedure.


\subsection{Inversion for ice thickness change from ocean altimetry}

The recovery of the simple inversion is good, showing that the Bayesian framework is able to effectively use the ocean altimetry data to constrain the ice thickness change. The sensitivity tests are suggestive that even with poor calibration of the priors, the ocean altimetery is informative enough to constrain the ice thickness change, which is encouraging for the application of this method to real data where the priors are likely to be imperfect. The repeatability of this across multiple inversion suggests that this is not a feature of a single true data source, but rather a general feature of the method.

The improved $z$-scores from the Bayesian inversion suggest it is more effective at recovering the true GMSL contribution from ice melt than the old method, as it correctly accounts for the non-uniform spatial structure of the sea level fingerprints associated with different ice sources. The old method's large $z$-scores indicate that it is systematically underestimating the uncertainty, likely due to its reliance on the SSHC proxy which does not capture the full complexity of the sea level response to ice melt. The Bayesian framework, by contrast, incorporates a more comprehensive model of the sea level response, leading to more accurate uncertainty estimates and improved recovery of the true GMSL contribution.

\subsection{Joint inversion using ice, firn, and ocean dynamic changes}

The inversions show good recovery of the detail and good sensitivity when using all data types. There are clear trade offs between the model paramters, as expected, and the method does well to disentangle these variable sources.

Knock-out tests show that there is information gained from the data types, specifically ice altimetry constraining the trade-off between the different densities effectively. The supplementary figure shows that SSH altimetry is critical for constraining ODT, which makes intuitive sense as it provides the spatial coverage needed to separate ocean dynamic signals from ice-driven fingerprints.

The loss in ocean dynamic topography detail is acceptable, given the altimetry noise parameter (1\,mm standard deviation) and so only recovering features over this noise level is expected.
